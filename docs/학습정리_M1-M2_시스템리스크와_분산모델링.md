# Part 1 · M1 — 시스템 리스크

## M1 · 레슨 1 — 비정상성·창발성·네트워크 전염·그림자 금융

**시스템 리스크가 보통 위험과 무엇이 다른가?**

1. **금융공학 = "도구로 문제를 푸는 기술"** — 도구와 숫자를 써서 문제를 푸는 일. 배운 기술을 새 상황에 적용한다.

2. **비정상성(Non-stationarity)의 저주 — "백미러만 보고 운전하기"**
   - **정상성(stationary):** 통계적 성질(평균·분산 등)이 시간에 따라 그대로 유지됨.
   - **비정상성(non-stationary):** 그 성질이 시간에 따라 변해버림.
   - 시스템 리스크는 드물게 터지고 터질 때마다 양상이 달라서 **본질적으로 비정상**에 가깝다. 과거를 보는(backward-looking) 관점만으론 부족하고, **앞을 보는(forward-looking)** 관점이 중요하다.

3. **창발성(Emergent Property) — 레고탑과 구성의 오류**
   - 부분 하나하나는 안 위험한데, **다 합쳐 놓으면 새로운 위험이 튀어나오는 것.**
   - 비유: 레고탑 — 각 블록은 멀쩡해도 높고 빽빽이 쌓으면 "와르르 무너질 위험"이 새로 생긴다.
   - **구성의 오류(fallacy of composition):** 부분의 합 ≠ 전체의 위험.

4. **네트워크 — 노드·엣지·전염, 그리고 간접 노출**
   - **노드(node):** 개별 기관. **엣지(edge):** 그들 사이의 연결(거래·노출).
   - **간접 노출(indirect exposure):** A가 C와 직접 거래하지 않아도, A→B→C 사슬을 통해 C의 부도가 A를 끌어내릴 수 있다.
   - **전염(contagion):** 충격이 연결을 따라 퍼지는 현상. 직접 연결만 따라오지 않는다.

5. **그림자 금융(Shadow Banking)과 탈중개화**
   - **그림자 금융:** 은행이 아닌 곳이, 원래 은행이 하던 자금 공급(신용중개)을 하는 것 — "은행 감독자의 감시 밖"에서.
   - **탈중개화(disintermediation):** 전통적 은행 중개를 거치지 않음 → 감독자 눈에 잘 안 보임.
   - **규제의 두 시선:** **미시건전성(microprudential, 나무를 본다)** = 개별 은행 건전성, **거시건전성(macroprudential, 숲을 본다)** = 시스템 전체. 나무가 다 건강해 보여도 숲이 병들 수 있으므로 거시건전성이 필요하다.

> **레슨 1 So What:** 시스템 리스크는 **창발적·비정상적**이며, **네트워크 전염**과 **그림자 금융**을 통해 퍼진다.

## M1 · 레슨 2 — 파이어세일·CCA·Granger 인과·PCA

1. **파이어 세일(급매)과 회계 방식**
   - **역사적 원가 회계(historical cost):** 자산을 취득가로 기록.
   - **시가 평가 회계(mark-to-market):** 자산을 현재 시장가로 기록 → 가격이 떨어지면 **즉시 자본이 깎인다.**
   - 기본 회계 등식: **자산 = 부채 + 자본** → **자본 = 자산 − 부채.** 자본 = 0이면 파산.
   - **파이어 세일 전염(fire-sale contagion, 경기순응적·pro-cyclical):**
     ① 자산값 하락 → ② 자본 방어를 위해 매도 → ③ 매도 압력이 가격을 더 떨어뜨림 → ④ 다른 회사도 매도. 고레버리지 회사는 자본이 순식간에 녹는다. 2007년 8월 "퀀트 멜트다운"의 붐비는 거래(crowded trades)에서 똑같이 발생.

2. **대마불사(Too Big to Fail)와 우발 청구권 분석(CCA)**
   - **우발 청구권(contingent claim):** 특정 사건이 일어나야 보수가 생기는 청구권(옵션처럼).
   - **CCA의 핵심 발상: 자본 = 콜옵션.** 머튼 모델(Merton model)처럼 회사 자본을 자산에 대한 콜옵션으로 본다.
   - 입력값: 자본의 시장가치, 자본의 변동성, 무위험 이자율(연율), 디폴트 장벽(만기 부채의 액면가), 만기까지 기간, CDS 스프레드.
   - **도덕적 해이(moral hazard):** 구제될 걸 알면 위험을 더 진다. **정상화 계획(resolution plan, '리빙 윌/living will')**으로 대비. 암묵적 보증의 가치를 측정.

3. **네트워크 분석과 그레인저 인과 — 위험의 "방향" 찾기**
   - **상관관계 ≠ 인과.**
   - **그레인저 인과(Granger causality):** X2의 과거값만 쓸 때보다 **X1의 과거값을 함께 쓰면 X2의 미래를 더 잘 예측**하면, X1이 X2를 그레인저-유발한다고 본다 → **예측적 인과(predictive causality).**
   - `statsmodels`의 `grangercausalitytests`, 그리고 `granger_causation_matrix`로 "_x" 변수가 "_y" 변수를 그레인저-유발하는지 검정. **p-값이 작을수록** 인과 증거가 강하다.

4. **주성분 분석(PCA) — 복잡한 걸 핵심 방향으로 압축**
   - **고유벡터(eigenvector) = "방향"**, **고유값(eigenvalue) = 그 방향이 "얼마나 중요한가".** 고유값이 클수록 그 주성분이 더 중요.
   - **세 가지 시스템 리스크 측정치:**
     - ① **상위 20개 주성분 노출 합산** (하이퍼파라미터: 몇 개를 쓸지).
     - ② **흡수 비율(Absorption Ratio, AR)** = (선택한 주요 고유값들의 합) / (전체 고유값들의 합). **AR이 갑자기 커진다 = 소수의 공통 요인이 시장 전체를 좌우하기 시작 = 시스템 리스크 증가 신호.** (주의: AR은 "흡수 비율"이지 "자기회귀(AR, auto-regression)"가 아님.)
     - ③ **고유벡터 중심성(Eigenvector Centrality)** — 인접 행렬(adjacency matrix) 기반. "영향력 있는 친구를 많이 둔 사람이 영향력 있다"(SNS 비유). `NetworkX`의 `eigenvector_centrality`.

> **레슨 2 So What:** "자본 = 자산 − 부채"로 부실을 보고, Granger로 **방향**을, PCA로 **집중도**를 잰다.

## M1 · 레슨 3 — 조건부 위험과 유동성: DIP·CoVaR·CoRisk·SES

공통 정신: **"시스템이 나쁠 때"를 조건으로 걸고** 위험을 잰다 (Co = conditional).

1. **부실 보험료(DIP, Distressed Insurance Premium)**
   - 복습 — **기대손실(Expected Shortfall, ES):** 손실이 기준선(예: 상위 5% 최악 구간)을 넘었을 때, 그 넘은 경우들의 **평균 손실.**
   - **DIP 정의:** "금융 시스템 전체가 큰일 났을 때, 그 손실에 대한 보험을 든다면 보험료가 얼마일까?" CDS 스프레드에서 거꾸로 추정.
   - 3가지 입력값: **PD(부도확률)·상관계수·기준선.**
   - 직관(은행 10개 = 전체 시스템 가정, PD 15% 고정, 상관계수만 변화):

     | 상관계수 | DIP(비율) | 100만 유로당 보험료 |
     |---|---|---|
     | 낮음 | 0.000275 | 275 유로 |
     | 중간 | 0.0216 | 21,640 유로 |
     | 높음 | 0.04255 | 42,550 유로 |

   - **가장 중요한 교훈 — 비선형(non-linear):** 상관계수 ↑ → 보험료(DIP) **폭발적으로** 증가. 상관이 +1에 가까워질수록 시스템이 통째로 무너질 확률이 급증한다.
   - **기준선을 15% → 5%로 낮추면?** 보험료가 오히려 **올라간다.** 해석 ① 공제액(deductible): 기준선이 낮을수록 보험사가 더 많이 물어줌. 해석 ② 풋옵션 비유. 단, "기준선만 바꾸는 실험" ≠ "실제 위기"(실제 위기에선 PD도 오르고 상관도 +1로 간다).

2. **CoVaR (조건부 VaR)**
   - 복습 — **VaR:** 일정 확률로 잃을 수 있는 최대 손실액.
   - **CoVaR:** "특정 회사가 부실에 빠졌다고 가정했을 때, 시스템 전체의 VaR이 얼마나 변하는가."
   - **ΔCoVaR = (그 회사가 부실일 때 시스템 VaR) − (그 회사가 정상일 때 시스템 VaR).**
   - ΔCoVaR가 **크다 = 시스템적으로 중요한(위험한) 회사.** (예: 유럽 52개 은행 분석.)

3. **CoRisk — 방향이 있고 비대칭이다**
   - **분위수 회귀(quantile regression):** 보통 회귀가 "평균"을 보는 반면, 분위수 회귀는 "특정 분위수"(예: 꼬리)를 본다.
   - **비대칭(asymmetry):** 충격은 한 방향으로 더 세다. 예 — AIG가 위험해지면 베어스턴스 스프레드가 약 **+250%** 오를 걸로, 반대로 베어스턴스가 위험해져도 AIG는 **+100%(2배)**만. 그래서 시스템 리스크는 **"누가 누구에게"**를 따져야 한다.

4. **그 밖의 측정치들**
   - **SES(시스템 기대손실, Systemic Expected Shortfall)**
   - **MES(한계 기대손실, Marginal Expected Shortfall)**
   - **카일의 람다(Kyle's lambda):** 유동성 측정치.

> **레슨 3 So What:** 모든 측정치의 공통 정신은 **"시스템이 나쁠 때를 조건으로 걸고"** 위험을 재는 것 (Co/Systemic).

# Part 2 · M2 — 분산의 모델링과 헤징

## M2 · 레슨 1 — 변동성 거래: 분산 스왑·거래소/OTC·ISDA 마진

1. **변동성과 분산 — 위험 자체를 거래한다**
   - **분산 = 변동성²**, **변동성 = √분산.** 예) 변동성 0.2(=20%) → 분산 = 0.04.
   - **분산 스왑(variance swap):** 가격의 **방향과 상관없이**, 분산이 커지면(=시장이 더 출렁이면) 이득. 변동성을 **하나의 독립된 자산 클래스**로 다룬다.
   - 대비: 옵션은 가격 **"수준(방향)"**에 가치가 달렸지만, 분산 스왑은 가격이 제자리여도 **출렁임 크기**만 커지면 이득.

2. **거래소(Exchange) 거래 vs 장외(OTC) 거래**

   | 구분 | 거래소 | 장외(OTC) |
   |---|---|---|
   | 규격 | 표준화·**대체가능(fungible)** | 맞춤형 |
   | 가격·체결 | 매칭 엔진 | 딜러 은행과 협상 |
   | 언제 | 표준 상품 | 맞춤·복잡 상품 |

   - **대체가능(fungible):** 같은 규격이라 서로 1:1로 교체 가능.

3. **장외 위험 관리 — ISDA와 마진(증거금)**
   - **ISDA 기본계약(Master Agreement):** 장외 파생거래의 표준 계약 틀.
   - **CSA(신용보강계약):** 담보(마진) 교환 규칙.
   - **마진(margin, 담보) 두 종류:** ① **개시 증거금(Initial Margin)** ② **변동 증거금(Variation Margin) — 매일** 손익을 정산해 주고받음.

4. **시가평가 마진 — 금 선물 예시**
   - 명목가(notional value) = 10,050 온스 × 30,000 ZAR = **301,500,000 ZAR.**
   - 0~3일차(만기)까지 매일 가격 변동에 따라 변동 증거금을 한 단계씩 주고받는다.

> **레슨 1 So What:** 매일 조금씩 주고받으면(변동 증거금) **거래상대방 위험(counterparty risk)이 확 준다.**

## M2 · 레슨 2 — 분산 스왑을 옵션으로 복제하기 (수식의 핵심)

1. **복제(Replication)와 헤징 — 왜 중요한가**
   - **복제:** 어떤 상품을 다른 상품들의 조합으로 똑같이 만들어내는 것. → 수익 구조를 정확히 이해하고 **헤징(위험 상쇄)**할 수 있다.

2. **상태가격(State Price) = 그 상태가 일어날 확률**
   - **애로-드브뢰 증권(Arrow-Debreu security):** "딱 한 가지 상태에서만 1을 주고, 나머지 모든 상태에선 0을 주는 증권." 그 **가격 = 시장이 믿는 (위험중립) 확률.**
   - **위험중립 가격결정(risk-neutral pricing):** 모든 우발 청구권의 가격 = Σ (그 상태에서의 보수) × (그 상태의 상태가격).

3. **옵션 가격에서 확률을 뽑아내기 — 브리든-리첸버거(Breeden–Litzenberger)**
   - 핵심 수식: **p(Sₜ, T; Sₜ, t) = ∂²P/∂K² │(Sₜ=K) = ∂²C/∂K² │(Sₜ=K)**
   - 즉 **옵션 가격을 행사가 K로 두 번 미분하면 위험중립 확률밀도가 나온다.** (P=풋, C=콜.)
   - 정규화: **∫ p(K) dK = 1** (모든 가능한 가격의 확률을 다 더하면 1).

4. **기대 보수를 적분으로 쓰고, 둘로 쪼개기**
   - 기대 보수: **Eₜ(g(Sₜ)│Sₜ) = ∫₀^∞ g(K)·p(K,T;Sₜ,t) dK.**
   - 선도가격 F를 기준으로 **분할:**
     **Eₜ(g(Sₜ)│Sₜ) = ∫₀ᶠ g(K)·(∂²P/∂K²) dK + ∫ꜰ^∞ g(K)·(∂²C/∂K²) dK.**
   - **낮은 가격 구간은 풋옵션으로, 높은 가격 구간은 콜옵션으로** 복제(각 영역에서 거래가 활발한 옵션 사용).
   - **스패닝 정리(Spanning Theorem):** 보수 함수가 **두 번 연속미분 가능(twice continuously differentiable)**하기만 하면, 풋·콜을 행사가별로 무한히 잘게 모아 **어떤 보수든 복제**할 수 있다.

5. **보수 함수 선택 — 왜 하필 로그 계약(Log Contract)?**
   - 로그 계약: **log(Sₜ/F) = ∫₀ᵀ d log Sₜ = ∫₀ᵀ (dSₜ/Sₜ) − ∫₀ᵀ (σ²(Sₜ)/2) dt.**
   - 여기서 **∫(σ²/2)dt가 바로 우리가 찾던 "실현 분산(realized variance)".**
   - **핵심 결과: E(∫₀ᵀ σ²(Sₜ) dt) = −2·E(log(Sₜ/F)).** (실현 분산의 기대값 = −2 × 로그 계약의 기대값.)
   - g(Sₜ)=log(Sₜ) → g′=1/Sₜ, g″=−1/Sₜ². "두 번 연속미분 가능" 조건을 만족하므로 콜·풋 묶음으로 복제 가능.

6. **옵션 묶음 비중 정하기 — 감마를 일정하게 (1/K²)**
   - 목표: **달러 감마(dollar gamma)가 모든 행사가에서 일정**해지도록.
   - g″ = −1/S²에서 나오는 결과: **각 행사가 K 옵션의 비중 ∝ 1/K²** (행사가 제곱에 반비례).

7. **누가, 왜 분산 스왑을 거래하나**
   - (가) **변동성에 직접 베팅**하려는 사람 — 롱/숏.
   - (나) **이미 변동성 숏인 사람**(예: 합병 차익거래자, 벤치마킹 투자자, 변동성↑ 시 손해 보는 주식·펀드) — 헤지 위해 **롱.**
   - (다) **이미 변동성 롱인 사람** — **숏.**

> **레슨 2 So What:** **1/K² 비중의 옵션 묶음**으로 분산 스왑을 복제한다.
> 핵심 수식: **p = ∂²C/∂K² = ∂²P/∂K²**, **E[∫σ²dt] = −2·E[log(Sₜ/F)]**.

## M2 · 레슨 3 — 점프를 넣어 변동성 더 잘 재기: 레비 과정·순서통계량

1. **왜 이토(Ito) 과정 → 레비(Levy) 과정인가**
   - **이토 과정:** **d(log S) = μ dt + σ dW.** μdt = 드리프트 항, σdW = 브라운 운동(연속·매끄러움) 항.
   - **문제:** 갑작스러운 **점프(jump)**를 못 담는다.
   - **레비 과정:** **d(log S) = (드리프트) + (연속 브라운 운동)ᶜ + (점프 항).** 점프 항은 **포아송 과정(Poisson process)**으로 모형화. (Spadafora 가정에선 드리프트를 0으로 설정.)
   - 직관: 레비 = 이토의 매끄러운 부분 + "툭툭 튀는 점프" → 현실의 급변을 담는다.

2. **순서통계량(Order Statistics)으로 점프 찾아내기**
   - **순서통계량:** 표본을 크기순으로 정렬했을 때 1차(최솟값)·k차·n차(최댓값) 등 각 순위의 값. 각 순서별로 "어디쯤에서 나올 가능성이 큰지"가 다르다.
   - 복습: **pdf(확률밀도함수)·cdf(누적분포함수)·iid.** 예) f(x)=e⁻ˣ (x≥0).
   - **점프를 찾는 핵심 아이디어:** "우리가 가정한 기준 분포(예: 정규분포)에서 나왔다고 보기엔 **너무 크다(또는 너무 작다)**" → 점프로 판정.
   - **핵심 수학적 사실(논문 부록 식 33):** k차 순서통계량의 cdf는 **불완전 베타 함수(incomplete beta function)**로 표현된다.

3. **통합 분산과 OS 추정기 — 단계별 알고리즘**
   - 목표: 점프를 벗겨낸 **깨끗한 연속 변동성 σ** 추정.
   - **OS 추정기 절차(바깥/극단부터 하나씩 벗겨내기):**
     - 1a 단계 — 가장 큰 **양수** 검사 → 점프면 제거.
     - 2a 단계 — 가장 큰 **음수** 검사 → 점프면 제거.
     - 양수 끝과 음수 끝을 번갈아 검사하며 극단값을 하나씩 벗긴다. **양수 하나를 점프로 빼면 σ가 달라지므로 매번 다시 계산해 비교**한다.
     - 반복(두 번째로 큰 값, 두 번째로 큰 음수…) → 점프를 뺀 "깨끗한 연속 변동성 σ" 완성.
   - **주의:** 작아 보여도 점프일 수 있다.
   - **확장판 — 이분산성(heteroskedasticity):** 변동성이 시간에 따라 달라지는 경우로 확장.

> **레슨 3 So What:** **드리프트 + 연속 확률 항(브라운 운동) + 점프 항**(레비 과정)으로 모형화하고,
> **순서통계량(k차 cdf = 불완전 베타 함수)**으로 점프를 분리해 **깨끗한 연속 변동성**을 얻는다.

# 마무리 — 전체 한눈에 요약

## M1 — 시스템 전체의 위험을 잰다
- 부분은 멀쩡한데 합치면 터지는 **"창발적" 위험**, 그리고 **"비정상성"**.
- **"자본 = 자산 − 부채"**로 부실을 보고, **그레인저 인과**로 방향을, **PCA**로 집중도를 본다.
- **DIP·CoVaR·CoRisk** — 자산 상관이 +1로 갈수록 위험이 **비선형으로 폭발**.

## M2 — 출렁임(분산)을 거래하고 더 정확히 잰다
- **"출렁임의 크기(분산)"에만 베팅** (분산 = 변동성²).
- 옵션 가격 두 번 미분으로 확률 추출: **p = ∂²C/∂K² = ∂²P/∂K²**.
- 실현 분산 = 로그 계약: **E[∫σ²dt] = −2·E[log(Sₜ/F)]**, 복제 비중 ∝ **1/K²**.
- **레비 과정**(d log S = μdt + σdW + 점프)과 **순서통계량**으로 점프까지 잡아낸다.

| M1 · PCA | AR = (주요 고유값 합)/(전체 고유값 합) | 흡수 비율 ↑ = 공통요인 지배 = 시스템 리스크 ↑ |
